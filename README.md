# ⚙️ Installation

To run this project locally, make sure you have **Git** and **Node.js** installed.

## 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

## 2. Navigate to the Project

```bash
cd portfolio
```

## 3. Install Dependencies

```bash
npm install
```

## 4. Start the Development Server

```bash
npm run dev
```

## 5. Open in Browser

```text
http://localhost:5173/
```
